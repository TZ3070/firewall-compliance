# 防火墙跨标准映射报告 v1

## 范围与结论

本报告连接以下目录中的防火墙控制项：

- GB/T 22239—2019：等级保护通用要求和条件场景要求。
- JR/T 0071.2—2020：金融行业等级保护要求。
- GB/T 20281—2020：网络型防火墙产品能力。

JR/T 0072—2020 到 JR/T 0071.2—2020 的 291 条 `measures` 关系已经保存在统一目录中，本文件不重复复制。

当前跨标准映射共 102 条：

- `equivalent`：23 条。
- `refines`：17 条。
- `partial`：13 条。
- `supports`：49 条。
- 人工确认关系：29 条。
- 待确认问题：0 条。

所有跨标准关系均设置 `standalone_pass_allowed: false`，不能仅依赖映射复用其他标准的合规结论。

## 产品范围

当前只启用 `network-based-firewall`。所有 GB/T 20281 映射都必须同时满足：

```text
product_type == network-based-firewall
product_security_level in [该控制项适用的 basic/enhanced 等级]
```

增强级专属控制只在 `product_security_level == enhanced` 时参与检索和判定。Web 应用防火墙、数据库防火墙和主机型防火墙专属能力保留在源目录中，但不进入当前网络型防火墙判定。

## 未映射的 GB/T 22239 控制项

以下 4 条为工业控制场景要求。JR/T 0071.2 当前整理范围没有工业控制扩展，不能建立金融标准对应关系：

- `GB22239-FW-ICS-001`：工业控制系统分区和技术隔离。
- `GB22239-FW-ICS-002`：工控边界部署访问控制并禁止通用网络服务。
- `GB22239-FW-ICS-003`：工控安全域边界防护失效告警。
- `GB22239-FW-ICS-004`：工控广域网通信加密认证和访问控制。

## 未映射的 JR/T 0071.2 控制项

以下 11 条属于金融行业新增要求或没有足够精确的通用标准/产品能力对应项：

- `JR0071-2-FW-003`：跨机构前置隔离与专用网络。
- `JR0071-2-FW-006`：非授权内外联检查、限制或阻断。
- `JR0071-2-FW-012`：系统服务端口梳理、关闭与开放审批。
- `JR0071-2-FW-013`：定期检查并锁定或撤销不必要账户。
- `JR0071-2-FW-019`：无线接入行为日志保存六个月。
- `JR0071-2-FW-034`：设备节点入侵检测和严重事件告警。
- `JR0071-2-FW-035`：安全计算环境设备生产专用。
- `JR0071-2-FW-CLOUD-008`：云客户网络节点流量监控。
- `JR0071-2-FW-IOT-001`：物联网授权节点接入和非法节点数据过滤。
- `JR0071-2-FW-IOT-003`：物联网攻击信息上报。
- `JR0071-2-FW-MOBILE-003`：无线攻击、高风险功能检测和非授权接入阻断。

这些控制项仍然拥有 JR/T 0072 测评单元映射，应直接按照金融标准实施和判定。

## 未映射的 GB/T 20281 控制项

以下 13 条没有进入当前跨标准判定：

- `GB20281-FW-001` 至 `GB20281-FW-004`：部署模式和路由能力属于产品网络能力，没有对应的强制金融控制目标。
- `GB20281-FW-007`：设备虚拟化不能单独证明云网络隔离或虚拟边界访问控制有效。
- `GB20281-FW-008`：当前金融控制目录没有单独的 IPv6 一致性和健壮性控制项。
- `GB20281-FW-011`：网络地址转换没有直接对应的金融合规控制项。
- `GB20281-FW-013`：动态开放端口是产品机制，不能直接等同于应用控制要求。
- `GB20281-FW-014`：IP/MAC 绑定不能单独证明非授权连接检查或物联网节点授权。
- `GB20281-FW-017`：网络数据会话超时不同于管理员登录会话超时。
- `GB20281-FW-021`：数据库应用内容控制不适用于当前网络型防火墙范围。
- `GB20281-FW-035`：事件统计不等同于设备运行状态监测或集中监测。
- `GB20281-FW-047`：产品安全保障材料不能通过现场配置快照验证。

## 判定边界

- `equivalent` 只表示控制目标对齐，不复用通过结果。
- `refines` 表示金融要求包含基线要求并增加约束。
- `partial` 必须与其他控制项和证据合并。
- `supports` 只证明产品具备相应能力，现场仍需验证功能已启用、参数正确且运行有效。
- 产品实验室性能结果不能替代生产环境容量和抗攻击验证。
- 条件场景关系只有在部署场景和产品等级条件同时满足时才可使用。

由于四份源目录仍处于 `Candidate` 状态，当前映射目录可用于检索、规则设计和候选评估，但不能直接生成最终合规结论。
