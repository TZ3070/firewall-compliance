# GB/T 22239—2019 防火墙相关要求扫描结果

## 1. 结果概览

本次扫描以 `GB/T 22239—2019《信息安全技术 网络安全等级保护基本要求》` 为标准来源，仅整理能够由防火墙配置、设备运行状态或设备日志直接或部分验证的要求。

整理结果：

- 通用防火墙控制族：36 个；
- 条件适用扩展控制：11 个；
- 推荐 P0 控制：18 个；
- 明确记录的排除或人工核验类别：6 类；
- 数据状态：`Candidate`，进入正式检测前仍需人工审核和引用绑定。

本结果不代表覆盖该标准的全部管理、人员、物理、建设和运维要求，也不能据此宣称设备或系统整体符合 GB/T 22239—2019。

## 2. 扫描和校验口径

1. 使用同版 DOCX 对全文进行条款号和关键词扫描。
2. 以 PDF 为权威来源，核对核心通用要求的原文、条款号和印刷页码。
3. 将第一至第四级中重复或增强的要求归并成逻辑控制族。
4. 每个控制保留各等级的源条款引用，不把高等级增强要求错误套用到低等级。
5. 云计算、移动互联、物联网和工业控制要求单独保存，只有部署上下文明确时才适用。
6. 标准中的“可”类可信验证要求不作为默认强制失败项。

正文印刷页码与当前 PDF 的关系为：

```text
PDF 物理页序号 = 正文印刷页码 + 6
```

## 5. 当前 Mock 可以直接覆盖的内容

当前 `default-firewall.json` 已经有以下可用事实：

- 默认访问控制动作和安全策略列表；
- 策略源区域、目的区域、地址、服务、动作和日志开关；
- SSH、HTTPS、Telnet、HTTP 管理协议；
- 管理接口和允许来源网段；
- 管理员、审计员角色和 MFA 绑定状态；
- 审计、策略、威胁日志开关；
- 本地日志留存和远程日志服务器；
- IPS、反病毒、DoS 防护状态；
- 高可用状态和配置同步状态；
- 时间同步状态和服务器。

仍需补充的关键字段：

```text
access_control.stateful_inspection_enabled
management.password_policy
management.login_policy
management.session_timeout_minutes
management.authentication_factors
management.default_accounts
management.roles
management.role_permissions
logging.audit_record_fields
logging.admin_operation_log_enabled
logging.audit_log_protection_enabled
threat_prevention.attack_logging_enabled
threat_prevention.severe_event_alerting_enabled
configuration_backup
monitoring
```

这些字段缺失时应返回 `NeedsReview`，不能直接判定 `Failed`。

## 6. 条件适用的扩展要求

扩展要求必须由明确部署上下文触发：

| 场景 | 候选控制 | 适用条件示例 |
|---|---:|---|
| 云计算 | 5 | 使用云防火墙、虚拟防火墙或承担虚拟网络边界控制 |
| 移动互联 | 1 | 防火墙承担有线和无线网络边界网关职责 |
| 物联网 | 1 | 防火墙承担感知节点或网关节点目标地址限制 |
| 工业控制 | 4 | 防火墙部署在工控与企业网或工控安全域边界 |

普通银行数据中心边界防火墙默认只执行安全通用要求。没有场景证据时，扩展项应为 `NeedsReview` 或不进入本轮清单，不能由关键词召回自动认定适用。

## 7. 不进入自动防火墙检测的内容

- 机房、门禁、防火、防雷、防水和供电等物理环境要求；
- 安全策略、制度制定发布、评审修订；
- 管理机构、人员录用离岗、培训和授权审批；
- 定级备案、方案设计、采购、开发、测试验收和系统交付；
- 运维审批、工单、备份执行记录、事件响应和外包管理；
- 使用“可”的可信验证增强要求。

上述内容不是标准层面的“不适用”，只是超出本项目的自动配置检测范围。报告中应作为覆盖边界披露，而不应生成 `NotApplicable` Finding。

## 8. 使用方式

机器可读候选目录位于：

```text
backend/data/catalog/gb-t-22239-2019-firewall-candidates.json
```

正式进入 `control-catalog-v1` 前，需要完成：

1. 由标准或测评人员确认每个候选控制的原子化粒度；
2. 将人工核对的 verbatim 原文写入版本化目录，并生成稳定 Qdrant point ID；
3. 校验召回正文的标准号、条款号、源目录指针和内容哈希；
4. 为自动项建立确定性规则和测试用例；
5. 为混合项声明配置证据与人工证据的边界；
6. 根据本次评估的等保等级选择对应引用，不能同时把四个等级都当作适用要求。
